# SanjayS-Portfolio

A professional portfolio website for Sanjay S, a B.Sc. Computer Science student with expertise in Java, Python, and modern web technologies.

## Features

- 🎨 Modern, responsive design with cyber-inspired theme
- 📱 Mobile-friendly interface
- 🎯 Interactive components and animations
- 📄 Downloadable resume with print/PDF export
- 🔧 Built with React, TypeScript, and Vite
- 🎵 Tech audio sound effects
- 🌐 Multiple portfolio sections (Skills, Projects, Experience, etc.)

## Tech Stack

- **Frontend**: React 19, TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Deployment**: GitHub Pages

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Deploy

```bash
npm run deploy
```

## Resume Download

The portfolio includes a built-in resume viewer and download feature:
- Click **VIEW** to open the resume in a modal
- Click **DOWNLOAD** to save as PDF
- Use the print functionality to generate a custom PDF

See [RESUME_DOWNLOAD_SETUP.md](./RESUME_DOWNLOAD_SETUP.md) for more details.
